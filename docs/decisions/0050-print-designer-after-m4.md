# 0050 — M4 prints with a default design; the print designer screen follows as M4b

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-12 |
| **Decided by** | Owner |

## Decision
- M4 prints A4 documents with a clean default design that follows design 09, and every issued document stores its **template version** ([0020](0020-print-template-designer.md)).
- The **print designer screen** (logo, colour, language, texts, margins) comes right after, as **M4b**.

## Why
- Keeps M4 a manageable size; reprints of M4 documents still match their original because the version is stored.
