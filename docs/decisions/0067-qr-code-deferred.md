# 0067 — No QR code on printed documents until e-invoicing

| | |
|---|---|
| **Status** | Accepted |
| **Date** | 2026-10-14 |
| **Decided by** | Owner |

## Decision
- Printed documents carry **no QR code** for now.
- The UAE does not require one on paper today. The e-invoicing programme ([0019](0019-einvoicing-via-accredited-provider.md)) will define what a QR code must hold. It is added then, as a locked field if the rules require it.

## Why
- A code printed now could hold the wrong content and would have to change later.
