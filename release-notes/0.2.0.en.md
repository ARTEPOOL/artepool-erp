The first version delivered by automatic update.

- The program updates itself from the internet, only at a safe time: no shift open, after a checked backup, at night or when you press "Install now".
- If an update fails, the previous version comes back by itself and the data stays as it was.
- Reinstalling the program never deletes the data. Deleting the data needs the word DELETE and the owner's password, and the backups are always kept.
- If database port 5432 is used by another program, the program picks another port by itself.
- The updates log is shorter: one line only when the state changes.
