# Release notes

One pair of files per version, shown to the owner in System health before an update is installed
(decision 0108), in plain words:

- `<version>.ar.md` — Arabic
- `<version>.en.md` — English

Both are required: the release workflow stops without them. Keep each under 4,000 characters and
write what changes for the shop, not how it was built.

Write the Arabic in the same plain Egyptian Arabic as the screens (decision 0110), and put each
change on its own line starting with "- ": System health shows one point per line.
