Clearer updates, and a "Check now" button.

- The Updates card has a **Check now** button: the server PC looks for a new version within 5 minutes. It still checks by itself every few hours and installs at night, as before.
- After an update, the card no longer shows the version you are already running as a "new version". It checks again at once and says "Up to date".
- Release notes show one point per line.
- If an update does not succeed, the setup's message and its log say why, and the previous version comes back by itself, as before.
- A PC that once had a test version from the GitHub tests says so, and what to do.
- "Kiosk lock is off" is now a bar above the screen and no longer covers a card.
- The external drive folder shows "Example: E:\" so it does not look already filled in.
