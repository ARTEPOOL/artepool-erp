The server PC's health in one place.

- A new "Server PC" card at the top of System health: the last backup, the backup key, free disk space, the services, the certificates, the server clock and the UPS. Each line is green, orange or red.
- Confirm once that a UPS is connected to the server PC; the program asks again after six months.
- The security certificate between the PCs and the server now renews itself 60 days before it ends, at night with no shift open, and is checked before it is used. If the renewal fails, the old one comes back and it is tried again the next night. Every renewal is in the audit log.
- Any problem with the server PC also shows on the owner dashboard.
