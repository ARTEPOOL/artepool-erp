اختار العميل وشوف رصيده على طول.

- مربع ملوّن تحت اسم العميل في فاتورة A4 والإيصال ونقطة البيع: أخضر مفيش عليه حاجة، أصفر جوّه الحد، برتقالي عليه فواتير متأخرة أو قرّب من الحد، أحمر عدّى الحد.
- المالك والمحاسب بيشوفوا المبالغ: المستحق، والمتأخر، وحد الائتمان، والمتاح، والدفعات المقدمة في سطر لوحدها. باقي المستخدمين بيشوفوا اللون والكلام بس.
- قائمة العملاء فيها عمود "المستحق" وفلتر "عليهم فواتير متأخرة".
- صفحة العميل فيها الفواتير المفتوحة وعمر كل واحدة، وأقدم تاريخ مش مدفوع، وصافي المركز.
- فاتورة A4 ممكن تطبع "ملخص الحساب" (الرصيد السابق، وهذه الفاتورة، والمدفوع الآن، وإجمالي الرصيد المستحق)، ومتسجل مع الفاتورة فإعادة الطباعة بتطلع نفس الأرقام. شغال لعملاء الآجل، وتقدر تغيّره من الإعدادات ← مصمم الطباعة.
