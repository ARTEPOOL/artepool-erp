A Windows account for the cashier, printed documents that never come out blank, and the unit price on A4 invoices shown excluding VAT.

- Printed invoices, notes and receipts never come out blank: the program waits for its fonts before printing.
- Credit and debit notes print the original invoice's number and date.
- The unit price and the discount on A4 invoices are now excluding VAT, like the taxable amount beside them. The shelf price, the label and the POS screen are unchanged.
- The company's name is spelled «آرتيبول» everywhere.
- A Windows account for the cashier, «الكاشير»: a standard account, not an administrator. The PC signs in to it by itself and the app opens on the PIN screen. The data, backup and key folders are closed to it, and it cannot stop the server.
- It is set up once from the Emergency tool: "Set up / repair the cashier account", written to the audit log. The steps are in the server install guide, part 8.
- System health has a new line for the cashier account. It says "Not set up yet" until you set it up.
- Windows Update does not restart the server PC from 8 in the morning to midnight (once the cashier account is set up).
- The ARTEPOOL data folder is closed to standard Windows accounts.
