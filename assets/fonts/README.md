# Fonts (decision 0068)

| File | Font | Used for |
|---|---|---|
| `ge-ss-tv-medium.otf` | GE SS TV Medium (Boutros International) | Arabic letters only, on every screen, A4 printout and the thermal receipt |

- Digits and Latin letters come from IBM Plex Sans Arabic (bundled through `@fontsource`): this
  Arabic font draws the digits 0–9 as Arabic-Indic digits, which must never appear on invoices.
- The owner confirmed the licence allows this use (decision 0068).
- Tw Cen MT Condensed Extra Bold (headings) is added when its file arrives.
